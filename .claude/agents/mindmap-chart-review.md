Issue up to **10 SEPARATE `Bash` tool calls per turn** (never a shell `for` loop in 1 `Bash` call) via `workflow-delivery-serial.local.py`, then pass `workflow-preflight.py check` (do not `--help`/`grep` `.claude/tools/*.py`).

On `"PASS"`, run `mindmap-gates.py render-chart` and `mindmap-gates.py validate-chart` (plus `scripts/hype_radar/check_chart.py` if Hype intake applies) before returning paths and verdict to MAIN.
