# Retain genuine explanations of unchanged instructions

Owner update, 2026-11-08. Follow `.claude/commands/_instruction-understanding.md` when a reviewer or other role revisits instructions. This supersedes older blanket instructions to rewrite EVERY unchanged source explanation on each check. Keep complete applicable rules, actual access and understanding, fresh source checks and independent artifact/application review. A file on disk, delivery receipt or automatic boolean is never proof of understanding.

Where the existing local protocol requires per-source explanations, the first reading remains complete. For the same actor, role/phase, canonical job and uninterrupted conversation/context epoch, use `instruction-understanding.py challenge` and write a short genuine CURRENT access/understanding and task-application confirmation. Explain changed/new sources and current handoffs freshly. Reference valid prior explanations for the unchanged rules rather than repeating them. Use the helper's `record` to retain explicit provenance, then the normal preflight check. No generated confirmations, copied answers presented as new understanding or fabricated PASSes.

Existing independent reviewers use `inspect` to see the fresh confirmation/delta and exact prior evidence references. Read original explanations once if they have not actually been inspected in the retained context; retrieve them again whenever needed. Continue judging rule application to the current candidate, findings and counters. Context loss, compaction, another actor/role/job or unclear understanding requires the normal complete reading/application; never restore an old epoch. Resume the existing reviewer for corrections when its real context is retained.

On sites without an existing detailed local explanation gate, keep their normal instruction-delivery and independent application checks. Do not add a new per-document attestation requirement, copy Layer3's local activation, or invent an extra checkpoint. Preserve all SEO, factual profiles, 1/2/3 review budgets, exclusions, professional obligations, source/testing honesty, exact-render/live checks and native release exceptions. No human gate is added.
