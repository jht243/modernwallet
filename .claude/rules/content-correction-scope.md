# Small corrections: preserve valid evidence, review the actual change

Owner update, 2026-11-08. Mindmap Pass and its callers must read `_content-correction-scope.md` before correcting audited content. This supersedes older blanket instructions to repeat all factual research after every small correction. Preserve the 1/2/3 shared content-review budget, all findings, full SEO, independent review, exclusions, professional obligations and native client/upsell release exceptions.

Capture full affected renders as usual. Before the INITIAL audit, the manifest lists actual per-route `correctionContentFiles` and complete source-evidence `reviewDependencies` references. The renderer seals a machine-only source boundary. For a later small correction, use `content-correction-scope.py prepare` against the actual last recorded review. A `targeted` result permits an independent recheck of the changed passage and its context, source diff and prior findings, plus fresh full-render/coherence/SEO checks. Carry only exact previously sufficient factual findings explicitly allowed by that proof; do not reopen every unchanged source or repeat unaffected factual investigations. Record the real report with this helper's `record` command; use its `sources` command to retain all dependencies. It never generates a PASS. The recheck still consumes the next existing round.

A `full` result requires the normal review of the affected page(s), without restarting counters or unrelated pages. Material meaning, figures, safety/legal/medical/investment claims, recommendations, links/schema/layout, shared templates/assets, missing prior evidence, unrelated changes or exhausted budgets cannot use a narrow correction. The reviewer must reject a purported typo that changes meaning. No new human gate.
