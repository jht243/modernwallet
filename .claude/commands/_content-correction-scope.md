# Small correction review

Owner instruction, 2026-11-08. Applies to ordinary editorial Mindmap Pass and callers. Preserve all local restrictions, original authorization and the existing phases. Native paid-client/upsell release paths retain their own rules. The previous risk profiles and single 1/2/3 content-review budget remain unchanged; a targeted independent recheck uses the next round and cannot extend that budget.

## Before the initial full audit

Use the normal complete rendered capture with `workflowKind: "mindmap-pass"`. Each route's manifest adds `correctionContentFiles`, the exact real content files for that route. The manifest's `reviewDependencies` lists the complete immutable internal source/evidence references (`path`, `sha256`) supporting factual judgments, including relevant professional-review evidence. These are real dependency records, not synthetic source lists. Preserve the existing handoff and independent application requirements.

The renderer records `correctionBoundary`: an internal hash inventory of source/configuration/assets and archived declared content. This machine-only inventory must not be delivered wholesale to reviewers or shown to visitors. Keep all affected route captures and boundary/source artifacts with the normal internal receipts. Run the initial independent content audit normally, with complete seven rendered checks, the applicable factual checks and honest findings. Record its actual PASS/FAIL with the existing review-budget helper.

## After a correction

Capture the complete current affected pages again using a NEW immutable output filename and the same manifest, job and counters. Then run:

`python3 .claude/tools/content-correction-scope.py prepare --previous-snapshot OLD_SNAPSHOT --previous-review ACTUAL_LAST_REVIEW --snapshot CURRENT_SNAPSHOT --route ROUTE --out NEW_SCOPE.json`

`mode: targeted` means the machine proved a small rendered text change with unchanged markup/headings/metadata/schema/links and unaffected sibling routes, corresponding reader-text source changes, unchanged other source/assets/evidence, complete prior findings and a same-day unfinished canonical job. The scope contains changed passages with context and source paths, not another copy of all research. Inspect the source delta directly from the boundary's immutable content artifacts. Do not send the complete machine boundary to the AI.

`mode: full` gives concrete reasons the affected page needs normal review. Never override the result, relabel factual changes as typos, reset a job, or re-audit unrelated passing pages. Numeric changes, consequential qualifiers, recommendations, shared layout/assets, source changes outside the page, missing/incomplete evidence and accumulated corrections widen the scope. A reviewer who discovers changed meaning rejects the narrow correction honestly. Resolve it through the remaining normal budget; once all allowed audits are exhausted, automatically publish the exact final audited snapshot unless blocked by a narrow direct legal/physical-harm `liabilityBlock` (e.g. incorrect medical dosing or acute safety hazard — general medical pricing, locations, attribution wording, and SEO/style findings never block).

## The actual independent recheck

Reserve the next round using the EXISTING `content-review-policy.py reserve` command and the same job. The independent reviewer must still have genuine current access to and understanding of all applicable rules; context loss requires the existing complete reading/application process. Prior receipt delivery is not proof of understanding. The reviewer reads the changed passage with sufficient surrounding context, actual source delta, original findings and prior approved evidence. Reopen any affected claim or dependency. It need not research unrelated unchanged claims again.

The real rendered report retains its normal author/reviewer independence, exact current snapshot/fingerprint, profile, `reviewBudget`, fresh current `riskAssessment` and local instruction applications. Each targeted route adds:

- `correctionScope`: the helper's source-bound `scopeArtifact` reference.
- `carriedFactualChecks`: only the explicitly allowed unchanged previously sufficient factual fields. Their complete original status/evidence/artifact records remain byte-for-byte identical. A prior FAIL is never carried as approval.
- `carriedRenderedChecks`: only the proof's unchanged sufficient `sourceSupport`, `testingAndAttribution` and `scopeAndExclusions` findings. Preserve their exact records. The new source/render proof plus genuine independent meaning/scope check binds them to this correction; no repeated investigation of unchanged sources or testing claims is needed.
- `correctionReview`: actual `changedPassage`, `meaningAndScope`, `priorFindings` and `unchangedEvidence` judgments, each with honest PASS/FAIL and specific evidence. PASS requires all four to pass. This is part of the existing audit, not a separate review round.

Always freshly verify `centralFacts` for the affected passage, `riskClassification`, `seoQuality`, and any required `instructionUnderstanding`. All seven rendered checks remain covered. Freshly verify full-render coherence/layout, dates/schema and links/indexability against the complete current capture, using mechanical evidence where appropriate. Carry only the explicitly proven unchanged source/testing/scope findings; do not repeat unaffected factual research. Recheck every previously failed field. Keep required professional review: only genuinely unchanged exact prior professional evidence may be carried, never a changed treatment/legal claim. No automatic testing labels or fabricated credentials.

Record the actual report using `python3 .claude/tools/content-correction-scope.py record --review ACTUAL_REPORT`. It validates scope and preserves genuine evidence before recording the result through the EXISTING counter; it never creates a verdict. Publication's rendered check validates the same proof again. Keep existing full build/link/exact-live/host checks. Use `sources --review ACTUAL_REPORT` for the internal dependencies, including original boundaries/source artifacts, and retain the appended journal after live closure. Ordinary full reviews continue using the normal helper. Already sufficient exact unchanged pages keep their existing approvals; no new review is needed for a source-only formatting change that leaves the actual semantic render identical.

The helper never treats a missing baseline as PASS. Its conservative fallback is a normal affected-page review, within the same budget. It does not invalidate the existing risk-policy stamp, discard old findings or introduce a human gate.
