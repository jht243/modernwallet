## The tool on this page
A "Checklist" dropdown with eight choices: Home Buying Checklist, Home Selling Checklist, Rental Checklist for Renters, Landlord Checklist, Home Inspection Checklist, Final Walkthrough Checklist, Move-In / Move-Out Condition Checklist, First Apartment Checklist. Choosing one shows that checklist's questions (for example type of home, when it was built, how you're paying, state and four local-condition switches: "Winters reach freezing", "Hurricane-prone coast", "Wildfire area", "Earthquake area") and the matching list. "Print or save as PDF" prints only the checklist as a worksheet. Ticks and notes are saved only in the reader's browser. No signup.
