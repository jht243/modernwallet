# Phase 7 — sitemap + IndexNow prep (mindmap-pass 2026-09-21)

## Sitemap
The sitemap is **generated at build time** by `@astrojs/sitemap` (`astro.config.mjs:13`), filtered by `isNoindexedPath`. There is no hand-maintained sitemap file to edit.

- All 8 new routes appear in `dist/sitemap-0.xml`, **exactly once each** (verified by grep count).
- **This site's sitemap emits no `<lastmod>` element at all** (`grep -o "<lastmod>" dist/sitemap-0.xml` → 0 hits). So there is nothing to refresh for substantively-changed pages and, equally, no way to wrongly stamp a link-only page. The Phase 7 lastmod rules are structurally satisfied. Freshness on this site is carried by the per-page `updated` field, which drives the visible "Updated …" byline and JSON-LD `dateModified`.
- Consolidation is advisory-only this run and no legacy `.consolidation.txt` exists, so no routes are removed.
