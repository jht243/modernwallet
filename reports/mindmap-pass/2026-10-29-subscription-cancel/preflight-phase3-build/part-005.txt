## Existing site author by default; missing person never holds publication

Owner instruction, 2026-10-29. Every content routine, including unattended local, global and cloud Mindmap runs, automatically reuses the active site's established author. Discover the existing author object/profile in the shared template, site configuration, author registry, About page and comparable pages. Prefer the existing category/template mapping, then the site's configured default. Reuse that person's exact established identity, profile URL and supported credentials; preserve the site's existing attribution format. Record the source once in the run notes and pass the selected identity through the existing page/template fields. Never copy another fleet site's author or create a different person for each page. Do not ask the owner to select or assign an author.

If no person is configured, continue with the site's existing publisher/editorial identity and an honest Organization author where the template/schema supports it; otherwise omit the optional personal byline. Adding a person later is optional follow-up in existing internal notes. A missing named author, Person schema, credentialed reviewer, `reviewer`/`reviewedBy` or `lastReviewed` is not a preparation, writing, audit or publication blocker. Do not defer an otherwise publishable page for that reason, require a new profile before continuing, create a separate human gate, or show "author pending"/"review pending" to visitors. Never invent a person, qualifications, a professional-review claim or a review date.

YMYL, consumer-rights, legal, financial and medical categorization alone does not require assigning a named professional. Use accurate primary sources and the existing informational scope, disclosures and safety exclusions. Narrow unsupported or out-of-scope recommendations to a supported informational answer within the existing authorization. Genuine completed professional review may retain its actual reviewer and date; an author's presence alone does not establish professional review. This owner rule supersedes older generic named-credentialed-reviewer and Person-only authorship requirements in shared or local instructions.

The independent Phase 4 reviewer remains an automatic reviewer agent, distinct from the writing agent. Internal manifest/evidence `author` and `reviewer` values identify those workflow actors; they do not require a visitor-facing person's name, professional credentials or a client appointment. Preserve independent factual/usefulness checks, testing-evidence decisions, local medical/psychedelic testing exclusions, the complete rendered-page audit, publication authorization and exact live verification. Authorship fallback adds no new gate and never substitutes for those automatic checks.
