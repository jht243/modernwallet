# IRS Pub 915 Worksheet 1 (2025 edition) — for the calculator spec
L1 net benefits (SSA-1099 box 5). L2 = L1 × 50%. L3 = other income (Form 1040 lines 1z,2b,3b,4b,5b,7a,8). L4 = tax-exempt interest (line 2a). L5 = certain exclusions. L6 = L2+L3+L4+L5. L7 = Schedule 1 adjustments (lines 11–20, 23, 25). L8 = L6−L7 (if L7 ≥ L6 → none taxable).
L9 base: $32,000 MFJ; $25,000 single/HOH/QSS/MFS-lived-apart. MFS lived together: skip to L17 = L8 × 85%.
L10 = L8−L9 (if ≤0 none taxable). L11: $12,000 MFJ, $9,000 others. L12 = max(L10−L11,0). L13 = min(L10,L11). L14 = L13×50%. L15 = min(L2,L14). L16 = L12×85%. L17 = L15+L16. L18 = L1×85%. L19 taxable = min(L17,L18).
Source: https://www.irs.gov/publications/p915
