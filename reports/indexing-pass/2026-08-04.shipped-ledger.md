## Notes on diagnosis method for this run

Unlike a typical pass, this run's 89 `URL is unknown to Google` rows were diagnosed **not**
by re-grepping the last 30 commits for a specific per-URL fix, but by inspecting the live
template architecture, because every one of those 89 URLs belongs to one of four uniform,
data-driven page families:

- `/compare/*` — every entry in `src/data/comparisons.ts` / `comparisons-business.ts` is
  auto-listed on `/compare/index.astro` (`entries.map(...)`), and cross-linked via each
  entry's `relatedComparisons[]` array, rendered by `src/pages/compare/[slug].astro`.
- `/guides/*` — every entry in `src/data/guides.ts` is auto-listed on
  `/guides/index.astro` (`GUIDES.map(...)`).
- `/roundup/*` — every entry in `src/data/roundups.ts` / `roundups-business.ts` is
  auto-listed on `/roundup/index.astro` (`entries.map(...)`).
- Calculator spokes (`/mortgage/*`, `/portfolio/*`, `/retirement/*`, `/auto-loan/*`, and
  standalone tools like `/interest-per-day/`) — every registered calculator/spoke is listed
  on `/calculators/index.astro` via `spokesForCalc()` / the top-level `CALCULATORS.map()`
  loop, and cross-linked via each spoke's `relatedSlugs[]` array.

All four hub pages (`/compare/`, `/guides/`, `/roundup/`, `/calculators/`) are linked from
`SiteFooter.astro` on every page of the site. Spot-checked representative URLs from every
family present in this run's 89 (`portfolio/80-20-portfolio-calculator`,
`auto-loan/refinance-calculator`, `interest-per-day`, plus the compare/guides/roundup hub
templates themselves) confirm the link is present in the rendered output for each family.

**Conclusion:** none of the 89 `URL is unknown to Google` rows has a missing-internal-link
defect to fix — the site's hub/spoke architecture already links every one of them from a
footer-reachable hub page. This is a discovery/crawl-budget gap, not a linking bug: 27 of
the 89 correspond to pages first added in the last 24-72h (`competitor-monitor`,
`podcast-pain-pass`, `comparison-content-auto`, `ga4-top-pages-pass` runs on 2026-08-02
through 2026-08-03 — see `git log --oneline -30` above), so Google simply has not crawled
them yet. Action: IndexNow re-submission only (Phase 7/9), no code change, no `lastmod`
bump (they didn't change this run).
