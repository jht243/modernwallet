# Current page: 529 Savings Calculator (/529-savings-calculator/)

Projects college-fund growth: enter child's current age, current balance, monthly contribution,
expected return, optional college-cost target. Worked example: $300/month at 6% return from age
0 -> ~$116,206 by age 18 ($64,800 contributions + $51,406 tax-free growth). Assumes ONE child,
ONE ongoing monthly contribution stream (a lump-sum-only scenario is technically supported by
setting monthly contribution to $0 and using "current balance" as the lump sum, but this is not
explained anywhere on the page).
