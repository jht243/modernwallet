# Current page: Operating Cash Flow Calculator (/operating-cash-flow/)

This calculator uses the FASB ASC 230 INDIRECT method only: start with net income, add back
non-cash items (depreciation, amortization), adjust for working capital changes (receivables,
inventory, payables). Worked example on the page: $120,000 net income + $25,000 depreciation +
$5,000 amortization = $30,000 non-cash add-backs; $15,000 AR increase + $10,000 inventory
increase − $8,000 AP increase = $17,000 working capital drag; OCF = $120,000 + $30,000 − $17,000
= $133,000.
