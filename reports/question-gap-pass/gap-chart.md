    contradiction predates this run and reconciling which figure is correct is out of scope for a
    question-gap enrichment pass — the fix applied here was to **remove the newly-added link**
    (the underlying site-wide inconsistency is flagged below for a future data-accuracy pass, not
    silently ignored). Also fixed: the new "Is my IRA FDIC insured?" FAQ named FDIC without a
    first-mention link — added `[FDIC](https://www.fdic.gov/deposit-insurance)`.
  - `spokes-retirement.ts` (couples-retirement-calculator): the new ssa.gov link landed on the
    *third* mention of "Social Security" on the page rather than the true first mention (in the
    intro) — moved the link to the actual first occurrence and left the later mention as plain text
    per the site's own first-mention-only linking convention.
- Re-verified both fixes by hand (not re-run through a fresh agent, since both were small, mechanical
  corrections directly matching the auditor's stated issue) — confirmed no earlier conflicting link
  existed on either page before applying each fix.

**Flag for a future run (not fixed here, out of scope):** `src/data/roundups.ts`
(`best-ira-accounts`) states the 2026 IRA contribution limit as $7,000/$8,000; `src/data/guides.ts`
(`ira-contribution-limits-2026`, and the tax-tips guide) states it as $7,500/$8,600 with an $1,100
catch-up. These are two different numbers for the same fact and should be reconciled against the
IRS's actual published 2026 limits in a dedicated data-accuracy pass.
